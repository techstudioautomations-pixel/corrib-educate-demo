# Corrib Educate booking prototype

Interactive prototype for managing group enquiries, centre availability, confirmed bookings, documents, host families, and finance preparation.

## Demo notes

- This is a front-end prototype built with HTML, CSS, and JavaScript.
- Demo changes are saved in the visitor's browser using local storage.
- There is no shared database or authentication in this version.
- Use **Reset demo data** to restore the original example records.

## Run locally

Serve the folder with any static web server, then open `index.html` through that server.
